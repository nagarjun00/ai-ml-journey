# AI/ML Journey

A daily, hands-on log of me learning AI/ML from the ground up — no shortcuts, no skipped fundamentals.

This repo is my proof of work. Every notebook, note, and commit here reflects something I actually built or understood well enough to explain myself, not just followed along with.

## Why this repo exists

I wanted to actually understand AI/ML from the ground up instead of just learning to use APIs and calling it a day. So this is where I build that understanding — one concept, one notebook, one honest commit at a time. It's less a portfolio showcase and more a running record of the work.

## How I'm approaching it

- **Learn by doing.** Every concept gets implemented the same day it's learned — code first, not five videos before I touch a keyboard.
- **Notes in my own words.** Everything in `/notes` is written from memory after each session, not copy-pasted from a source. If I can't explain it myself, I haven't actually learned it.
- **Daily commits, real progress.** Each commit is real work — a model trained, a concept implemented, a comparison run — not a checkbox.

## Structure

```
ai-ml-journey/
├── notes/          # Concept notes, written in my own words after each session
├── notebooks/       # Jupyter notebooks — code, experiments, model comparisons
├── projects/         # Larger, standalone mini-projects as they come up
└── README.md
```

## Roadmap

Working through this in phases:

1. **Math + Python foundations** — linear algebra intuition, core Python/data tooling
2. **Core ML** — classical algorithms, model evaluation, Kaggle practice
3. **Deep Learning** — neural networks, CNNs/RNNs, PyTorch
4. **LLMs / GenAI** — transformers, prompting, RAG, agents
5. **AI Security** — adversarial ML, prompt injection, LLM red teaming — where this connects back to my core focus
6. **Specialization** — going deeper based on where my interest lands

Currently in  **Phase 1-2** .
